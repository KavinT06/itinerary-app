# Itinera

Day-by-day travel plans, generated by AI.


Enter your name, travel dates and a destination, and get a day-by-day itinerary: five timed activities a day
at named venues, a practical tip for each, notes on the destination and an estimated budget.

- **Live:** https://superitineraryapp.vercel.app
- Itineraries are generated by an AI model. Venues, opening hours and prices are suggestions and are **not
  verified** against live data. Check them before you travel.
- Nothing is stored: no accounts, no database. An itinerary lives in your browser tab.

## Stack

Next.js 15 (App Router) · React 19 · Tailwind CSS 4 · JavaScript · [Groq](https://groq.com) for generation ·
optional Upstash Redis for shared limits and caching · deployed on Vercel.

## Run it locally

Requires Node.js 22 or newer and a Groq API key (https://console.groq.com/keys).

```bash
git clone https://github.com/KavinT06/itinerary-app.git
cd itinerary-app
npm install
cp .env.local.example .env.local     # then put your key in GROQ_API_KEY
npm run dev                          # http://localhost:3000
```

Check the setup at http://localhost:3000/api/health. It should report `"ai": "configured"`.

| `SMOKE_AI=1 npm run smoke:ai` | One real generation against Groq. Uses quota |

## API

`POST /api/trips`

```json
{ "destination": "Alfama, Lisbon, Portugal", "startDate": "2027-03-01", "endDate": "2027-03-03", "createdBy": "Asha" }
```

Success returns `{ "success": true, "trip": { … }, "requestId": "…", "cache": "miss" }`.

Errors return a message, a stable code and whether retrying can help:

```json
{ "error": "Too many requests. Please wait 42 seconds and try again.", "code": "RATE_LIMITED", "retryable": true, "retryAfter": 42, "requestId": "…" }
```

Trips can be 1 to 14 days. The full contract and the list of error codes are in
[docs/architecture/LLD.md](docs/architecture/LLD.md).

`GET /api/health` reports whether the application is configured. It does not call the AI provider.
